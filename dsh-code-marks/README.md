# dsh-code-marks

在 DSH 对话里**选中一段代码或一句话 → 打个标签**，它就固定在右侧栏的「标记」面板里；点一下标记，对话直接滚回那段原文并高亮。

解决的是这件事：追问一多，正确题解就被顶上去，回看要翻很久。标记存在对话流之外，所以**永远顶不掉**。

## 怎么用

1. 在助手的回答里，用鼠标选中一段代码或一句话（也支持跨行选）。
2. 松手后浮出标签条，点一个标签（`核心逻辑 / 疑问 / 易错点 / 待复习`，或点 `＋` 现建一个）。
3. 右栏自动打开「标记」页签，这条标记排在最上面。

回到标记：在面板里点那条标记 → 对话滚动到原文、闪一下、并把这段文字选中。

面板关掉以后怎么找回来：右栏页签条的 **添加** 按钮 → 引导页 → 「标记」胶囊。

## 面板里能做什么

| 操作 | 说明 |
|---|---|
| 点一条标记 | 跳回原文（旧内容没加载时会自动点「加载更早」把历史拉回来，最多 16 次） |
| 悬停一条标记 | 在对话里临时高亮它（不跳转） |
| 标签 chip 行 | 按标签筛选，括号里是该标签的条数 |
| 搜索框 | 按选中原文或备注过滤 |
| ✎ | 给这条标记写/改备注（比如「这里为什么要 -1」） |
| × | 删除这条标记 |
| ⚙ | 标签管理：新建、改名、换颜色、删除（删除标签时它的标记会转到第一个标签） |

高亮颜色跟着标签走，6 种颜色可选，深浅色主题都用同一套半透明底色。

## 数据存在哪

都在这台机器的浏览器存储里（`localStorage`），不上传、不进会话日志：

- `dsh.code.marks.v2.<sessionId>`：这个会话的标记（原文、位置、标签、备注、时间）
- `dsh.code.marks.v1.tags`：标签表（全局共享，所有会话通用）

每个会话的标记互相独立；换会话就看那个会话的标记。清空：设置里清站点数据，或删掉这两个 key。

## 它是怎么做到「跳得准」的

一条标记不存 DOM 节点（React 会重渲染、代码块会从 plain 换成高亮版、流式输出一直在追加），只存四样东西：

1. `data-chat-node-key` / `data-chat-anchor-key`：这条消息在对话里的身份（原样存，不解析）
2. 消息内文本偏移 + 选中的原文
3. 前后各 48 个字符的上下文
4. `data-chat-turn`：第几轮（兜底用）

解析时按四级降级：精确锚点 → 同 node 的行 → 精确原文 → 上下文打分（含「空白全部忽略」的兜底，所以重新缩进的代码也能认出来）。

高亮用 **CSS Custom Highlight API**（`CSS.highlights` + `::highlight()`），只建 Range 不改 DOM，所以不会被 React 的 diff 冲掉；对话变化时以 240ms 去抖重建 Range。

## 已知限制

- **折叠起来的过程组**里的文字选不到；要先展开它。标记落在被折叠的内容里时，点标记会尝试点开那个组，失败则提示「先往上滚一点」。
- 原文被改写（比如重新生成过这条回答）到认不出来的程度时，只能定位到这条消息，高亮位置对不上——面板会明确提示，不会瞎标。
- 跳转是程序化滚动，DSH 会认为「读者自己滚了」，于是暂停「跟随最新」；对话自己跳轮次也是这样。
- 只对**助手的回答**（`assistant-step`）开放标记；工具调用、终端输出暂不支持。
- 标记只存在本机浏览器，不跨设备同步。

## 卸载

DSH 设置 → 插件 → 找到 `dsh-code-marks` → 停用或卸载（也可以 `plugin_manager` 的 `remove_bundle`）。卸载后浏览器里的标记数据仍在，重装即回来。
